# Sampler

<img width="549" height="479" alt="Screenshot 2026-06-15 at 11 12 33 AM" src="https://github.com/user-attachments/assets/90230641-a4f2-49e4-b480-583e4d3c6591" />


This tool creates a subfolder of samples in the form of symlinks. 

It utilizes stratified sampling for a more accurate sampling of the session files.

The default sampling amount is set to be 10% of both U and S files.


<img width="786" height="457" alt="Screenshot 2026-06-15 at 11 13 20 AM" src="https://github.com/user-attachments/assets/2e52cac7-5453-4314-9040-3a3df1f55c08" />

## Use
### Sampling a folder of files:
- This tool is used primarily to sample a session folder for files to open during the QC process
