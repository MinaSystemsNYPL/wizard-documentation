# RTG Mover

<img width="547" height="459" alt="Screenshot 2026-06-15 at 11 39 43 AM" src="https://github.com/user-attachments/assets/9adbb856-dd80-4b24-a712-98a25077b699" />


This tool sends the renamed files in a folder to the RTG folder for ingest into the Repository.

*Files will not be moved if they are not renamed, ie. if they are still named 1s, 1u, 2s, 2u, etc.

The remaining "shell" folder that contains the QC folder of JPGs and the manifests and logs generated by Wizard is sent to /Traveling-Pants/Moved-to-RTG. 


## Use
### Delivering a folder of files to RTG:
- This tool is used primarily to deliver a folder of renamed files ready for ingest by the RTG folder into the repository.
